User Guide

Welcome to the HJ PDE Playground! This guide explains how to use the benchmarks, implement solvers, and submit your results.

1. Getting Started with Benchmarks

  1. Go to the Benchmarks page
  2. Browse the hierarchical structure: Topic → Class of Problems → Specific Cases
  3. Click on a collapsible section to view problem details
  4. Download the benchmark code for the problem you're interested in

2. Understanding the Benchmark Structure

Each benchmark includes:

  • benchmark_code.py: The benchmark implementation with Hamiltonian and initial conditions
  • details.md: Problem description, references, and specific instructions
  • test.py: Test script to evaluate your solver

3. Implementing Your Solver

4. Running the Test Script

  1. Save your solver in a file (e.g., my_solver.py)
  2. Import your solver in the test script
  3. Run the test script: 
    python test.py
  4. The script will output error metrics and performance measures

5. Submitting Your Results

You can submit your results in two ways:

Option 1: Direct Upload

  1. Go to the Submit page
  2. Select "Results" as submission type
  3. Upload your results file (CSV format)
  4. Fill in additional information (author, description, etc.)

Option 2: GitHub Repository

  1. Create a GitHub repository with your solver implementation
  2. Include the test script in your repository
  3. Go to the Submit page
  4. Select "GitHub Link" as submission type
  5. Provide your repository URL
  6. Our system will use GitHub Actions to validate your submission

7. Tips and Best Practices

  • Read the details.md file for each benchmark to understand specific requirements
  • Test locally first before submitting to ensure your solver works correctly
  • Include documentation in your code for better understanding
  • Follow naming conventions specified in the benchmark interface
  • Check error handling in your solver for edge cases

8. Getting Help

If you need assistance:

  • Check the benchmark-specific instructions in the details.md file
  • Visit our community forum for discussions
  • Submit an issue on our GitHub repository
